# DARTRIO – Downloads

Autoscoring für Dart mit 5 Kameras.

**Webseite:** https://dartrio2026.github.io/dartrio-updates/

**Neueste Version:** [Releases › Latest](https://github.com/dartrio2026/dartrio-updates/releases/latest)

| System | Datei | Installieren |
|---|---|---|
| Mac (Apple-Chip M1 oder neuer, macOS 12.3+) | `DARTRIO-<Version>.dmg` | DMG öffnen → DARTRIO auf „Programme“ ziehen. Beim ersten Start: *Systemeinstellungen › Datenschutz & Sicherheit › „Dennoch öffnen“* |
| Windows 10/11 (64 bit) | `DARTRIO-Setup-<Version>.exe` | Setup starten. Bei „Der Computer wurde durch Windows geschützt“: *Weitere Informationen › Trotzdem ausführen* |

Updates: DARTRIO meldet neue Versionen beim Start selbst („Update verfügbar“) – ein Klick genügt.
Kalibrierung und Daten bleiben bei Updates erhalten.
